# 🏢 Agents Office — Next.js + TypeScript + Tailwind + MUI

บริษัทซอฟต์แวร์ที่พนักงานเป็น AI ทั้งหมด แยกเป็นแผนก/ทีม แต่ละคนนั่งโต๊ะของตัวเองบนแผนที่ออฟฟิศ pixel art
สั่งงานทางหน้าเว็บ แล้วดูทีมทำงานจริง: นั่งพิมพ์ เดินส่งงานข้ามแผนก คุยกัน และส่งมอบไฟล์โค้ด

## เริ่มใช้งาน

ต้องใช้ Node.js 18.18+

```bash
make setup     # ติดตั้ง dependency + สร้าง .env (แล้วเปิดไฟล์ใส่ ANTHROPIC_API_KEY)
make mock      # โหมดจำลอง ไม่เรียก AI ไม่เสียเงิน ไว้ดูหน้าตา
make dev       # โหมดพัฒนา ใช้ Claude API จริงถ้ามี key
make           # ดูคำสั่งทั้งหมด
```

เปิด http://localhost:3000 แล้วพิมพ์โจทย์ เช่น "ทำเว็บ to-do list เก็บข้อมูลเป็นไฟล์ JSON"
ผลงานอยู่ใน `workspace/<เวลา>/` (กดเปิดไฟล์จากรายการทางขวาได้เลย)

ไม่ใช้ make ก็ได้: `npm install` → `npm run dev` (ใส่ key ใน `.env`, ใส่ `MOCK=1` เพื่อใช้โหมดจำลอง)

## โครงสร้างโปรเจกต์

```
src/
├─ app/
│  ├─ page.tsx, layout.tsx, globals.css
│  └─ api/
│     ├─ events/route.ts        SSE: ส่งสถานะ/เหตุการณ์สดไปหน้าเว็บ
│     ├─ task/route.ts          POST: รับโจทย์ (+mode, path) แล้วเริ่มให้ทีมทำงาน
│     ├─ run/[id]/diff, apply   ดู diff / กดนำไปใช้กับโปรเจกต์จริง
│     └─ workspace/[...path]/   เปิดดูไฟล์ที่ทีมสร้าง (กัน path traversal)
├─ components/
│  ├─ OfficeApp.tsx             หน้าหลัก + เชื่อม SSE
│  └─ Sidebar.tsx               ทีมงาน / บันทึกงาน / รายการไฟล์
└─ lib/
   ├─ agents.ts                 รายชื่อพนักงาน + นิสัย (system prompt) + ตำแหน่งโต๊ะ
   ├─ orchestrator.ts           ลำดับงานข้ามแผนก (สร้างใหม่/แก้ของเดิม/รีวิว) + โหมดจำลอง
   ├─ project.ts                คัดลอกสำเนา / diff / นำไปใช้ + สำรองไฟล์
   ├─ llm.ts                    เรียก Claude API
   ├─ bus.ts                    สถานะฝั่งเซิร์ฟเวอร์ (รอด hot-reload)
   ├─ office-engine.ts          วาดออฟฟิศ canvas + แอนิเมชันตัวละคร
   └─ types.ts                  type ของ event ทั้งหมด (ใช้ร่วม server/client)
```

## ทำงานกับโปรเจกต์เก่า

ตั้งค่าครั้งเดียว: ใส่ `PROJECTS_ROOT=` ในไฟล์ `.env` ให้เป็นโฟลเดอร์แม่ของโปรเจกต์ที่อนุญาตให้ AI แตะ (ดูตัวอย่างใน `.env.example`) แล้วรันใหม่
จากนั้นเลือกโหมดบนหน้าเว็บ แล้วพิมพ์ path ของโปรเจกต์ (เช่น `my-app` หรือ path เต็ม — ต้องอยู่ใต้ `PROJECTS_ROOT`)

| โหมด | ทำอะไร |
|---|---|
| ✨ สร้างใหม่ | สร้างโปรเจกต์ใหม่ ถ้าใส่โฟลเดอร์ปลายทาง จะมีปุ่ม "นำไปใช้" วางผลงานลงโฟลเดอร์นั้น |
| 🛠 แก้โปรเจกต์เดิม | แก้บั๊ก/เพิ่มฟีเจอร์ — AI อ่านโค้ดเดิม เลือกไฟล์ที่เกี่ยวข้อง แล้วแก้เฉพาะจุด (SEARCH/REPLACE) |
| 🔍 รีวิวอย่างเดียว | อ่านและรีวิว/อธิบายโค้ด ไม่แก้ไฟล์ ได้รายงาน `REVIEW.md` |

**ความปลอดภัย (โหมดแก้ของเดิม)**
1. AI ทำงานบน **สำเนา** ใน `workspace/<เวลา>/` — โปรเจกต์จริงยังไม่ถูกแตะ
2. เมื่อเสร็จ หน้าเว็บแสดง **diff ทีละไฟล์** ให้ตรวจ แล้วคุณกด **"นำไปใช้"** เองเท่านั้น
3. ก่อนเขียนทับ ไฟล์เดิมถูกสำรองไว้ที่ `<โปรเจกต์>/.ai-office-backup/<เวลา>/` (ย้อนกลับได้โดยคัดลอกกลับ)
4. ถ้าไฟล์จริงถูกแก้ระหว่างที่ AI ทำงาน ไฟล์นั้นจะ **ไม่ถูกเขียนทับ** (ติดป้าย ⚠)
5. ไม่ส่งไฟล์ลับให้ AI (`.env*`, `*.pem`, `*.key`, `id_rsa*`, `credentials*`) และข้าม `node_modules`, `.git`, ไบนารี, ไฟล์ > 300KB
6. จำกัดโปรเจกต์ไม่เกิน 1,500 ไฟล์ / 15MB — ถ้าใหญ่กว่านี้ให้ชี้ไปโฟลเดอร์ย่อย

> หมายเหตุ: เนื้อโค้ดของโปรเจกต์ (ยกเว้นไฟล์ลับ) จะถูกส่งไปยัง Claude API เพื่อให้ AI อ่าน — ตรวจสอบนโยบายของบริษัทก่อนใช้กับโค้ดที่เป็นความลับ

ออฟฟิศแสดงเป็นภาพ isometric 2.5D แบบ CSS 3D (โซนแผนก, Team Sync, Meeting Room, การ์ดสถานะเหนือหัวพนักงาน, ป้ายส่งงานบินข้ามโต๊ะ) · ทุกโหมดคลิกเลือกโฟลเดอร์ได้เหมือนกัน — โหมดสร้างใหม่จะบันทึกผลงานลงโฟลเดอร์ที่เลือกเมื่อเสร็จ (ไม่เขียนทับไฟล์เดิม) ถ้าไม่เลือกให้กดปุ่มดาวน์โหลด .zip เอง (ไม่ดาวน์โหลดอัตโนมัติ) · โหมดแก้โปรเจกต์/รีวิว: คลิกเลือกโฟลเดอร์โปรเจกต์ (ค่าเริ่มต้น = โฟลเดอร์แม่ของแอป เปลี่ยนด้วย `PROJECTS_ROOT`)

## Production (build + start)

```bash
cp .env.production.example .env.production   # ครั้งแรก (make build จะสร้างให้อัตโนมัติถ้ายังไม่มี) แล้วแก้ค่าตามต้องการ
make build      # next build — โหลด .env + .env.production
make start      # รัน production ที่ PORT (ค่าเริ่มต้น 3000)
```

- `.env.production` ใช้ตอน `make build` / `make start` เท่านั้น ส่วน `make dev` / `make mock` ใช้ `.env` + `.env.development`
- ค่าใน `.env.production` ชนะ `.env` จึงควรใส่เฉพาะค่าที่ต้องการให้ต่าง (บรรทัดที่ขึ้นต้นด้วย `#` จะไม่ทับค่าจาก `.env`)
- ไฟล์ `.env*` จริงไม่ถูก commit (ดู `.gitignore`) เหลือแค่ `.env.example` และ `.env.production.example`

## เลือกค่าย AI

รองรับ Claude / ChatGPT / Gemini — ใส่ key ของค่ายที่มีใน `.env` (`ANTHROPIC_API_KEY`, `OPENAI_API_KEY`, `GEMINI_API_KEY`; ตั้งรุ่นด้วย `MODEL`, `OPENAI_MODEL`, `GEMINI_MODEL`) แล้วเลือกค่ายได้ที่มุมขวาบนของหน้าเว็บ (เลือกได้เฉพาะค่ายที่ตั้ง key แล้ว และเปลี่ยนไม่ได้ระหว่างทีมกำลังทำงาน) key อยู่ฝั่งเซิร์ฟเวอร์เท่านั้น ไม่ถูกส่งไปหน้าเว็บ
